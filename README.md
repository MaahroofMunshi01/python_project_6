# Personal Journal Manager

## 📌 Project Overview

The Personal Journal Manager is a menu-driven Python application that allows users to maintain their personal journal digitally.

Users can add new journal entries, view previously saved entries, search for specific entries using keywords or dates, and delete all journal entries when required.

The application uses file handling to store journal entries permanently in a text file along with their date and time.

## 🚀 Features

- **Add New Entry:** Write and save personal journal entries.
- **View All Entries:** Display all previously saved journal entries.
- **Search Entries:** Find journal entries using keywords or dates.
- **Delete All Entries:** Delete the complete journal file after confirmation.
- **Automatic Timestamp:** Every journal entry is saved with its current date and time.
- **Empty Entry Validation:** Prevent saving empty journal entries.
- **Error Handling:** Handle file-related errors such as missing files and permission issues.
